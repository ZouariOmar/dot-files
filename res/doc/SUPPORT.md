## Getting Help

If you encounter issues or have questions:

- Run `./import --help` or `./export --help`
- Read the [API reference](../../docapi/README.md)
- Open a [GitLab issue](https://gitlab.com/zouariomar/dot-files/-/issues)
- Contact the maintainers

## Reporting Bugs

Please include:

- Operating system and Bash version (`bash --version`)
- Software version (`cat VERSION`)
- The exact command run, ideally with `-n` output
- Steps to reproduce
- Expected behavior
- Actual behavior

## Feature Requests

Suggestions are welcome through GitLab Issues.

## Security Issues

Please do not report security vulnerabilities publicly.
Refer to `SECURITY.md` for responsible disclosure.
